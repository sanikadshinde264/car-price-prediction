Car Price Prediction

A machine learning web application that predicts car prices using Python, Flask, Pandas and Scikit-learn.

Project Features

  • Car company and model selection
  • Year of manufacture
  • Kilometers driven
  • Fuel type
  • Machine learning based price prediction

Technology Stack

Python | Flask | Pandas | NumPy | Scikit-learn | HTML | CSS

Note: The machine learning prediction requires the Flask backend and cannot run directly on GitHub Pages.
